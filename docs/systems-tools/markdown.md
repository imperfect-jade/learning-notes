# Markdown 使用手册

这份手册用于快速查看并编写 Markdown。示例优先采用当前 MkDocs Material 站点可用的写法，包括标题锚点、表格、任务列表、脚注、代码高亮、数学公式、提示块等。

## 一、基本写作规则

### 1. 空行分隔段落

用途：Markdown 用空行区分段落、列表、代码块和标题。

```markdown
这是第一段。

这是第二段。
```

显示效果：

这是第一段。

这是第二段。

### 2. 文件结构建议

用途：让页面适合阅读和搜索。

```markdown
# 页面标题

简短说明页面用途。

## 一、主题

### 1. 知识点

说明 + 示例。
```

使用指南：

- 一个页面只使用一个 `# 一级标题`。
- 用 `##` 划分大章节，用 `###` 写具体知识点。
- 标题前后保留空行，列表和代码块更稳定。

### 3. 转义特殊字符

用途：显示 Markdown 语法字符本身。

```markdown
\*这不会变成斜体\*
\# 这不会变成标题
```

显示效果：

\*这不会变成斜体\*

\# 这不会变成标题

## 二、标题与目录

### 1. 标题

用途：建立页面层级，自动生成目录。

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

使用指南：

- 不要跳级，例如从 `##` 直接跳到 `####`。
- 标题文字尽量短，方便侧边目录扫描。

### 2. 自定义标题锚点

用途：固定链接地址，避免标题改名后链接失效。

```markdown
## 安装步骤 {#install}

[跳转到安装步骤](#install)
```

### 3. 页内跳转

用途：在同一页内快速跳转。

```markdown
## 二、配置 {#config}

[查看配置](#config)
```

## 三、文本样式

### 1. 加粗、斜体、删除线、高亮

用途：突出重点或标记修改。

```markdown
**加粗**
*斜体*
~~删除线~~
==高亮==
```

显示效果：

**加粗**  
*斜体*  
~~删除线~~  
==高亮==

### 2. 上标与下标

用途：写公式说明、单位或标记。

```markdown
H~2~O
x^2^
```

显示效果：

H~2~O  
x^2^

### 3. 下划线

用途：Markdown 本身没有通用下划线语法，可用 HTML。

```markdown
<u>下划线</u>
```

显示效果：

<u>下划线</u>

### 4. 行内代码

用途：标记命令、变量名、文件名、函数名。

```markdown
运行 `git status` 查看仓库状态。
```

显示效果：

运行 `git status` 查看仓库状态。

## 五、引用与提示块

### 1. 普通引用

用途：引用说明、定义、摘录或补充提醒。

```markdown
> 这是一段引用。
```

显示效果：

> 这是一段引用。

### 2. 嵌套引用

用途：表达引用中的引用。

```markdown
> 第一层引用
>> 第二层引用
```

显示效果：

> 第一层引用
>> 第二层引用

### 3. MkDocs 提示块

用途：写提示、警告、注意事项、可折叠说明。

```markdown
!!! note "说明"
    这里写补充说明。

!!! warning "注意"
    这里写风险提示。
```

显示效果：

!!! note "说明"
    这里写补充说明。

!!! warning "注意"
    这里写风险提示。

### 4. 可折叠提示块

用途：隐藏较长解释，保持页面简洁。

```markdown
??? tip "展开查看"
    这里是默认折叠的内容。

???+ example "默认展开"
    这里是默认展开的内容。
```

显示效果：

??? tip "展开查看"
    这里是默认折叠的内容。

???+ example "默认展开"
    这里是默认展开的内容。

## 六、链接与图片

### 1. 外部链接

用途：链接到网页。

```markdown
[Git 官方文档](https://git-scm.com/docs)
```

显示效果：

[Git 官方文档](https://git-scm.com/docs)

### 2. 相对链接

用途：链接站点内其他 Markdown 页面。

```markdown
[Git 使用手册](git.md)
[Python 学习](../programming/python.md)
```

使用指南：

- 同目录页面直接写文件名，如 `git.md`。
- 上一级目录用 `../`。
- MkDocs 会把 `.md` 链接转换成站点 URL。

### 3. 页内链接

用途：跳转到当前页面某个标题。

```markdown
## 代码块 {#code-block}

[跳转到代码块](#code-block)
```

### 4. 图片

用途：插入图示、截图、流程图。

```markdown
![图片说明](../assets/example.png)
```

使用指南：

- 方括号中写图片说明，便于无障碍阅读和搜索理解。
- 图片路径优先使用相对路径。
- 外链图片可能失效，重要图片建议保存到仓库中。

### 5. 带链接的图片

用途：点击图片跳转到目标页面。

```markdown
[![Markdown Logo](../assets/markdown.png)](https://www.markdownguide.org/)
```

## 十三、写作检查清单

### 1. 内容检查

用途：发布前快速确认页面质量。

- [ ] 页面只有一个一级标题。
- [ ] 标题层级没有跳级。
- [ ] 命令和路径使用行内代码。
- [ ] 多行代码块写了语言类型。
- [ ] 表格列数一致。
- [ ] 相对链接能跳转到目标页面。
- [ ] 图片有说明文字。
- [ ] 重要风险用提示块标出。

### 2. 构建检查

用途：确认 MkDocs 页面可以正常发布。

```bash
python -m mkdocs build --strict
```

### 3. 常见问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 列表没有正确嵌套 | 缩进不一致 | 子列表缩进 2 或 4 个空格 |
| 代码块吞掉后文 | 结束围栏缺失 | 检查是否有成对的 ``` |
| 表格错位 | 列数不一致 | 检查每行 `|` 数量 |
| 页内链接失效 | 标题变化或锚点不稳定 | 使用 `{#custom-id}` 固定锚点 |
| 公式不渲染 | 分隔符写错 | 行内用 `\(...\)`，块级用 `\[...\]` |

| 一级标题 | `# 标题` |

| 加粗 | `**文本**` |
| 斜体 | `*文本*` |
| 删除线 | `~~文本~~` |
| 高亮 | `==文本==` |
| 行内代码 | `` `code` `` |
| 无序列表 | `- 内容` |
| 有序列表 | `1. 内容` |
| 任务列表 | `- [ ] 任务` |
| 引用 | `> 内容` |
| 链接 | `[文字](URL)` |
| 图片 | `![说明](图片路径)` |
| 分隔线 | `---` |
| 行内公式 | `\(x^2\)` |
| 块级公式 | `\[x^2\]` |
| 脚注 | `文字[^1]` |
| 脚注定义 | `[^1]: 说明` |
| 提示块 | `!!! note "标题"` |
| 折叠块 | `??? tip "标题"` |
