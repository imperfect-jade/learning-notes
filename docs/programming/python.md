
# Python 学习大纲

## 第一阶段：环境搭建与基础语法
- **环境安装**：Python 解释器安装、PyCharm 或 VS Code 配置、虚拟环境 (venv/conda) 管理。
- **变量与数据类型**：
    - 数字 (int, float)、字符串 (str)、布尔值 (bool)。
    - 动态类型特性与类型转换。
- **运算符**：算术运算、比较运算、逻辑运算 (and, or, not)。
- **流程控制**：
    - 条件判断：`if`, `elif`, `else`。
    - 循环结构：`while` 循环、`for` 循环（配合 `range`）。
    - 循环控制：`break`, `continue`, `pass`。

## 第二阶段：组合数据类型
- **列表 (List)**：切片、增删改查、列表推导式。
- **元组 (Tuple)**：不可变特性、元组拆包。
- **字典 (Dictionary)**：键值对操作、常用方法 (`keys`, `values`, `items`)。
- **集合 (Set)**：去重、交集、并集、差集运算。

## 第三阶段：函数与模块化
- **函数基础**：定义 (`def`)、参数传递（位置参数、关键字参数、默认参数、可变参数 `*args`, `**kwargs`）。
- **作用域**：局部变量与全局变量 (`global`, `nonlocal`)。
- **匿名函数**：`lambda` 表达式。
- **模块与包**：`import` 机制、自定义模块、`pip` 包管理器使用。

## 第四阶段：面向对象编程 (OOP)
- **类与对象**：类的定义、构造方法 `__init__`、实例属性与类属性。
- **三大特性**：
    - **封装**：私有属性与方法。
    - **继承**：单继承、多继承、`super()` 调用。
    - **多态**：方法重写。
- **魔术方法**：`__str__`, `__repr__`, `__call__` 等。

## 第五阶段：进阶高级特性
- **异常处理**：`try...except...finally` 结构、自定义异常。
- **文件操作**：文本文件与二进制文件读写、`with` 上下文管理器。
- **迭代器与生成器**：`iter()`, `next()`, `yield` 关键字。
- **装饰器 (Decorators)**：闭包概念、函数装饰器、类装饰器。
- **并发编程**：多线程 (`threading`)、多进程 (`multiprocessing`)、异步 IO (`asyncio`)。

## 第六阶段：常用库与领域应用
- **数据分析**：NumPy (数值计算), Pandas (数据处理), Matplotlib/Seaborn (可视化)。
- **网络爬虫**：Requests (请求), BeautifulSoup/Lxml (解析), Scrapy 框架。
- **Web 开发**：Django 或 Flask 框架。
- **自动化运维**：OS 模块、Shutil 模块、Selenium 自动化。

## 第七阶段：实战项目建议
- **初级**：学生信息管理系统、计算器、天气查询工具。
- **中级**：个人博客系统、简单的网络爬虫、数据分析报告。
- **高级**：基于 AI 的图像识别应用、高并发 Web API 服务。

---
**学习建议**：
1. 坚持“守破离”：先模仿代码，再尝试修改，最后独立创作。
2. 多看官方文档和 PEP 8 代码规范。
3. 善用 `print()` 和调试器 (Debugger) 理解程序流转。
